# DAW ビジュアルデザイン — 参照動画ベースのライトテーマ

イシュー #20 のデザイン文書。参照動画の見た目を要素に分解し、DAW の画面に
どう適用するかを決める。採用の判断は ADR-0012（決定者：ユーザー）。

## 参照

- Emocute「Kawaii BASS [Riddim]」 https://youtu.be/KFA9YZselQ4?si=msWmGCSWLAVAcz-l
  （2026-11-19 公開、2分51秒）
- DAW の画面収録ではなく、楽曲解析をリアルタイム可視化したカスタム・
  ダッシュボード映像。取り入れるのは「画面の作り方」であって、解析機能ではない。

## 要素分解（参照の見た目）

- **配色**: ほぼ白に近い淡いクリーム／薄いピンクベージュの明るい下地。全体
  ハイキーで、影やグラデーションはほぼないフラットでマットな紙質感。
- **アクセント**: 鮮やかなホットピンク／マゼンタを1色だけ強く使う（ノート
  バー、円弧、現在のコードチップ）。副色はティール／ミントグリーン。文字と
  プレイヘッドは黒。
- **構成・密度**: 情報量は多いが、パネルごとに「03 NOTES」「04 DEGREE」
  「05 DOTS」のような小さな大文字ラベルを付け、グリッド状に整理する。
- **タイポグラフィ**: 階層は色ではなく「現在の値の文字サイズの大きさ」で
  付ける（現在のコード・BAR・TEMPO は大きな太字数字／ローマ数字）。
- **強調の原則**: 現在の状態だけをピンクの塗り・太字・大きな数字で強調し、
  それ以外は淡いグレー／細線に抑える。
- **図形**: 円（コード・ホイール）、細い直線、横長の矩形バー、角丸チップ、
  ドットマトリクスなど、丸みのある幾何学図形と細い線で「技術的だが
  柔らかい」質感を作る。
- **動き**: レイアウトは固定で、データだけが音楽に同期して変化する。
  プレイヘッド、伸びる円弧、密度（Mesh%）のような進捗指標でライブ感を出す。

## 質感と図形

- 影・グラデーションは使わない。面の区別は「一段だけ違うクリーム色」と
  1px の区切り線で行う。
- 矩形は角丸（目安：パネル 6px、チップ・クリップ 4px）。ボタンや現在値の
  表示は角丸チップにする。
- 線は細く（1px）、色はグレージュ線。強調したい線だけ黒またはピンクにする。

## タイポグラフィとパネルラベル

- 各パネルには連番＋大文字の小ラベルを付ける（例：`01 TRANSPORT`、
  `02 TIMELINE`、`03 MIXER`、`04 SAMPLER`）。ラベルは小さく（目安 10–11px）、
  グレージュで、パネル左上に置く。
- パネル内の「現在の値」（再生位置の小節、選択中クリップの音程、トラックの
  音量など）は大きく（目安 20px 以上）ウォームブラックで出す。階層は
  サイズで作り、色では作らない。
- 太字フォントは導入しない。太さの代わりにサイズとアクセント色で強調する
  （nannou の標準描画で収めるための制約）。

## 強調の原則

- アクセント（ホットピンク）を使うのは「今」のものだけ：再生中クリップ、
  現在の小節チップ、鳴っているサンプラーのキー、操作中（ドラッグ中）の
  スライダー、選択中のトラックの現在値。
- それ以外は淡色に抑える。ピンクが画面に増えたら、それは強調の失敗と
  みなして淡色に戻す。
- プレイヘッドは黒の細線。赤は使わない（旧テーマの名残を残さない）。

## ライブ感の要素（動き）

- レイアウトは固定し、値と図形だけが再生に同期して変わる。
- プレイヘッド：黒線＋現在の小節を示すピンクの角丸チップ。
- レベルメーター：バーの伸びで示す。通常はティール、ピーク付近だけ
  ホットピンクにする（参照の「進捗指標」の読み替え）。
- 進捗：再生位置／全体を横長バーまたは数値（小節・拍）で常時見せる。

## 適用範囲

- **まず DAW（`apps/daw`）だけ**に適用する。
- 動画編集（`apps/video-editor`）への展開は、DAW での結果を見てから
  別途判断する（この文書では決めない）。共通テーマ基盤を studio-core に
  置くこともしない（コアは GUI に依存しない、というアーキテクチャ
  ルールのため）。テーマは DAW アプリ内のモジュールに閉じる。

## 現状（#13〜#16・#18・#19 実装済み）との対応

現状の DAW GUI は一般的なダークテーマで、色は描画コードにリテラルで
散らばっている。対応は次のとおり。

| 要素 | 現状 | 新テーマ |
|---|---|---|
| 背景 | `main.rs` の `rgb(0.09, 0.09, 0.11)`（暗色） | ウォームクリーム `#FBF4EC` |
| パネル面 | `rgb(0.13, 0.13, 0.16)` 等の暗グレー | ペールクリーム＋グレージュ線の区切り |
| 文字 | `rgb(0.80, 0.80, 0.85)` 等の淡グレー | 現在値はウォームブラックで大きく、補助はグレージュ |
| クリップ色 | `timeline.rs`: 映像=青 `(0.25,0.45,0.85)`、音声=緑 `(0.25,0.70,0.40)` | 音声=ソフトピンク面＋ピンクの縁、映像=ミント面＋ティールの縁。再生中だけホットピンク塗り |
| プレイヘッド | `timeline.rs`: 赤 `(0.90, 0.20, 0.20)` | 黒の細線＋現在小節のピンクチップ |
| パネルラベル | なし（ラベルなしで直接描画） | 連番＋大文字の小ラベルを各パネルに |
| レベルメーター | なし | ライブ表示として新設（ティール→ピンク） |
| 色の置き場 | `main.rs`・`timeline.rs` にリテラル散在 | `theme.rs` の定数に集約 |

## 実装への分割

実装は EPIC #12 の子 PBI に分割する（着手順）：

1. テーマ基盤：色定数・ラベル描画などの土台を `theme.rs` に作り、背景と
   パネル面を新テーマにする
2. タイムライン画面への適用：クリップ・波形・プレイヘッド・現在小節チップ
3. ミキサー画面への適用：フェーダー・パン・現在値の大きな表示
4. サンプラー画面への適用：キー表示と現在の音程表示
5. 再生状態のライブ表示：レベルメーターと進捗表示

（起票した PBI 番号は、この文書の更新履歴とイシュー #20 のコメントに残す。）

着手は、ユーザーがこの文書を確認してデザインが確定してからにする。
