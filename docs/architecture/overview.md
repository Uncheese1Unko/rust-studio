# アーキテクチャ概要

## 全体像

```
        指示する AI                人間（GUI）            computer use / 自動テスト
            │                          │                          │
         MCP tools               nannou GUI                 HTTP/JSON API
            └──────────────┬───────────┴───────────┬──────────────┘
                           ▼                       ▼
                  studio-core：コマンド層（単一の変更経路）
                  モデル：Project / Track / Clip（時刻はミリ秒）
                           │
              ┌────────────┴────────────┐
        video-editor（動画編集）        daw（DAW）
        メディア入出力・描画            音声入出力・描画
```

## 要点

- 状態変更はコマンド適用のみ（ADR-0004）。コマンドは JSON シリアライズ可能で、
  失敗したら状態を変えない。
- コアは GUI・メディア・ネットワークに依存しない。重いメディア処理は
  アプリ側に閉じ、コアは素材への参照とパラメータだけを持つ。
- 状態の全量ダンプが API から取れる。画面で観測できることは API でも
  観測できる（ADR-0005）。
