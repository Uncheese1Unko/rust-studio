# ドキュメントの更新履歴

## 2026-11-22
* **Addition**: ADR-0016（ノートはクリップに統合し、音色（楽器）はトラック単位で参照する、PBI #67）を**採用**として追加した。決定者：ユーザー（2026-11-22 に推奨案の採用を決定）。`Clip.notes: Vec<Note>`（音高は MIDI ノート番号・絶対、開始はクリップ相対、ベロシティ付き、`#[serde(default)]` で旧 JSON 互換）と `Track.instrument: Option<Instrument>`（当面 `Sampler { source, root_note }`、Vital は Plugin バリアントの拡張点）を決め、追加コマンド（SetTrackInstrument・AddNote は #68、MoveNote・RemoveNote は #69）と、SplitClip は境界を跨ぐノートを分割点で切り、TrimClip は範囲外ノートを削除＋はみ出しをクランプする意味論まで確定した。Issue #67 の `needs-decision` を外して close し、#68〜#70 が着手可能になった。
* **Addition**: M3 の EPIC と PBI を7件追加した（EPIC #66、PBI #67〜#73）。ユーザーの要望（DAW で音色とメロディーを分離して管理できる機能、MIDI 読み込み、その完了後に Vital を取り込んで音色を作成できる機能）を受けて起票した一覧で、優先順と着手はユーザーが決めるため `status:ready` は付けていない。内訳：ノート／楽器モデルの設計（#67。ADR-0016 を「提案」として記録し採用はユーザーの設計判断とする `needs-decision` で、後続すべての前提）、メロディー再生（#68、blocked by #67）、ピアノロール編集（#69、blocked by #67）、MIDI 読み込み（#70、blocked by #67）、Vital 連携の方式調査（#71。ホスティング／ヘッドレス／外部連携と GPL の含意）、Vital 連携の実装（#72、blocked by #71 と方式決定と #68・#70。ユーザーの順序指定で分離・MIDI の完了後に着手）、音色の作成・管理（#73、blocked by #72）。今回は起票のみで実装には着手していない。
* **Addition**: 試験レポート issue-0063・issue-0064・issue-0065 を追加した。#63 は動画編集の複製・貼り付けへの offset_ms 引き継ぎ（#62 の SetClipOffset に追随、実アプリのプレビューログで素材時刻の継続を確認）。#64 は切り抜き背景フレーム選択のソース時刻を `media::source_time_ms` に統一。#65 は #63 のドライブ中に見つけたバグ（動画編集で編集中以外の Escape を押すとアプリが終了する。nannou 既定の Esc 終了が有効なままだった）の修正で、DAW #40 と同じく `set_exit_on_escape(false)` を入れた。
* **Update**: ADR-0014（トランジションは後続クリップの属性として持ち、合成は CPU ブレンド＋既存テクスチャ経路で行う）のステータスを「提案」から「採用」に更新した。決定者：ユーザー（2026-11-22 に推奨案の採用を決定）。理由は音声フェード（Issue #34）の持ち方との一貫性とモデルの単純さ。Issue #48 の `needs-decision` を外して close し、後続の実装 PBI #49 が着手可能になった。
* **Addition**: ADR-0015（mp4 書き出しはアプリ側レンダリング＋外部 ffmpeg エンコードの経路とする、PBI #52）を追加した。書き出し解像度・FPS はパラメータ（既定 1280×720/30fps）とし、音声は音声トラックのミックスを対象に、映像ソースの埋め込み音声は最初の実装では扱わない制限を明記した。あわせて試験レポート issue-0052 を追加した。
* **Addition**: ADR-0014（トランジションは後続クリップの属性として持ち、合成は CPU ブレンド＋既存テクスチャ経路で行う）を**提案**として追加した。Issue #48 の調査結論だが、モデルの持ち方と尺の意味論は設計判断のため、採用は人間の決定待ち（`needs-decision`）。合成方式は試作で裏付け済み。あわせて試験レポート issue-0048 を追加した。
* **Addition**: 試験レポート issue-0029（Undo/Redo の基盤）を追加した。studio-core にスナップショット方式・上限100件の History を置き、HTTP API と MCP に undo/redo を公開した。
* **Addition**: 試験レポート issue-0030（調査: ドラッグ＆ドロップ取り込みの可否と検証方法）を追加した。XDND を直接話す実験で、パスは取得できるがドロップ位置はイベントから取得できないことを確定し、ヘッドレス検証方法を確立した。
* **Addition**: 試験レポート issue-0059（動画編集 GUI トラック／クリップの色付け、固定パレット方式）を追加した。#58 のコア整備を使い、動画編集側は暗い画面に合わせた表示色とヘッダーの色帯で反映した。
* **Addition**: 試験レポート issue-0060（バグ修正: トラック追加・削除・リネームの境界ケース5件）を追加した。採番を最大番号 + 1 に変え、リネーム編集中のキー prev 同期とリロード時のセッション打ち切りを両アプリに揃えた。
* **Addition**: 試験レポート issue-0058（DAW トラック／クリップの色付け、固定パレット方式）を追加した。ColorTag と SetTrackColor / SetClipColor をコアに追加し、再生中は色付きクリップも ACCENT で描かれることをピクセル検証で確認した。
* **Addition**: 試験レポート issue-0057（動画編集 GUI トラックの追加・削除・リネーム）を追加した。追加した映像トラックのクリップがプレビューのアクティブなレイヤーとして扱われることを stdout の preview 行で確認した。
* **Addition**: 試験レポート issue-0056（DAW GUI トラックの追加・削除・リネーム）を追加した。追加行とミキサーパネルのレイアウト衝突を修正し、レビュー round 1 の指摘2件は実コード・原典確認のうえ固定テストと doc 明記で対応した。
* **Addition**: 試験レポート issue-0055（RenameTrack コマンドと MCP 公開）を追加した。
* **Addition**: ADR-0013（トラック／クリップの色付けはテーマ固定パレット方式とする、決定者：ユーザー、PBI #58・#59）を追加した。自由色は採らず、パレットに ACCENT は含めないこと、再生中は ACCENT で上書きする描画順序、データはパレット識別子で保持し未設定＝種別色・serde 既定で読むことを決めた。#58・#59 の `needs-decision` を外し、着手可能にした。あわせて基本操作と M2 の優先順は監督側（ヨーコ）に委任され、基本操作→共通基盤→DAW→動画編集の順でループを回す。
* **Addition**: M2 候補の PBI を26件追加した（#29〜#54）。ユーザーが実際にアプリを触った所感（「一般的な DAW／動画編集ソフトにある機能を持たせてほしい」）を受けて起票した機能一覧で、優先順はユーザーが決めるため `status:ready` は付けていない。内訳：共通基盤（Undo/Redo 基盤と GUI、ドラッグ＆ドロップ調査）、DAW（分割、複製・コピペ、フェード、BPM、メトロノーム、スナップ、ズーム、ミュート／ソロ、ループ再生、WAV 書き出し、ドロップ取り込み）、動画編集（分割、複製・コピペ、スナップ、ズーム、メディアビン、トランジション調査と実装、テキスト、音量とフェード、mp4 調査と書き出し、ドロップ取り込み）。クリップの配置・移動・トリミングとミキサーの音量・パンは M1 で実装済みのため起票していない。
* **Addition**: 「基本操作」の PBI を5件追加した（#55〜#59）。ユーザーが実機で触り「一般的な機能以前の問題」として指摘した、人が画面で触る基本操作の欠落への対応で、優先順はユーザーが決めるため `status:ready` は付けていない。内訳：トラック名変更のコア整備（RenameTrack コマンドと MCP 公開、#55。コマンド自体が存在しなかった）、両アプリの画面でのトラック（レイヤー）追加・削除・リネーム（#56・#57、blocked by #55）、トラック／クリップの色付け（#58・#59。モデルに色の項目自体がなかった。色の指定方式と状態色との衝突は設計判断として `needs-decision` を付け、判断確定まで着手しない）。ファイルのドロップ取り込み（#30・#42・#53）も同グループの一角として各イシューにコメントで関連付けた。
