## 実装の概要

- 方式は ADR-0011（決定者: エージェント）: MODNet（ONNX、
  Apache-2.0）を `ort` クレートの load-dynamic で読み、ワーカー
  スレッドでフレーム列をオフライン処理する。進捗は共有状態で
  GUI に表示し、UI は固まらない。
- 適用はコアのコマンド `SetClipCutout`（`Clip.cutout`、旧形式 JSON は
  false）。MCP の `set_clip_cutout` ツールでも変更できる。
- 合成は fg*α + bg*(1-α)。背景は同じ時刻を覆う別映像トラックの
  クリップ、無ければ単色。プレビューは合成済みフレームを優先表示。
- モデル／ランタイムが無い環境では「利用不可」と表示し、通常の
  プレビューを続ける（アプリは落ちない）。

## 受け入れ条件ごとの結果

### AC1: 人物部分を透過（マスク化）して別の背景と合成できる — ✅

- 実モデルでの受け入れ実行（証拠: [evidence/issue-0022/](evidence/issue-0022/)）:
  K キーで interview クリップに適用 → 60 フレーム分のマスク列と
  合成済みフレーム列が生成され、プレビューが合成結果に切り替わった。
- 合成の正しさは数値で検証: 保存されたマスク・前景・背景から
  fg*α + bg*(1-α) を再計算し、合成済みフレームと一致した
  （平均絶対誤差 約 0.93、丸めの範囲）。
