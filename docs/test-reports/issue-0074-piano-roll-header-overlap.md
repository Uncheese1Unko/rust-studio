# 試験レポート: Issue #74 バグ: ピアノロールのヘッダでパネルラベルとクリップ名表示が重なる

## 症状と原因

ピアノロールを開くと、左上のパネルラベル「06 PIANO ROLL」とタイトル
「<クリップ名> — instrument: ...」が重なって描かれ、両方とも読みにくい
（#70 の駆動証拠で確認された表示のみのバグ。機能への影響なし）。

原因: タイトルは x=120 に left_justify で置かれていたが、nannou の
left_justify はテキストブロックの左端アンカーとしては働かず、タイトルが
左へ広がってラベル（中心 52px）に重なっていた（レビューで指摘され、
当初の「中心固定」という記述を実態に合わせて修正した）。

## 再現と修正の確認

- 再現: issue-0070 の証拠画像で、ラベル域（x<110、見出し帯）の濃色画素
  （タイトル文字の侵入）が 46 個あることを実測した。
- 修正: タイトルの中心を、ラベルと操作ヒントの間の帯の中央に置くよう
  レイアウト計算を `pianoroll::header_title_center_x` に切り出した。
  単体テストで「400px 幅のタイトルでもラベル域・ヒント域に重ならない」
  ことを固定した。
- 修正後: GUI 駆動（drive.sh）でピアノロールを開き、ラベル域の濃色画素が
  0、タイトル域にはタイトルが描かれていることを確認した。
  スクリーンショットでも3要素（ラベル／タイトル／ヒント）が分離して
  読めることを目視確認した。

## レビュー

- 第1ラウンド: **APPROVE**（Major なし）。画素計測（46→0）とレイアウトテストの回帰ガードとしての有効性をレビュアーが実証確認した。
- Minor 1件: 根本原因の記述（コメント）が旧コードの実態（left_justify 配置）と食い違う → コメントとコミットメッセージを実態に合わせて修正した。
- フォローアップ候補2件（長いタイトル／狭い窓での再重なり、ヒント文の折り返し）は #77 に切り分けた。
