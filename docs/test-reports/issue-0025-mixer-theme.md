## 実装の概要

- `mixer.rs` に表示フォーマット `format_volume_db`（dB 表記）と
  `format_pan`（L-C-R 表記）を追加した。
- 描画（main.rs）: スライダーの溝はサンド（`PANEL_SUNK`）、つまみは
  角丸チップ（通常はペールクリーム面＋グレージュの縁、ドラッグ中
  だけホットピンク）、小さい値テキストはグレージュにした。
- 選択中トラックの音量・パンを、ストリップ右側に大きな数字
  （`VALUE_FONT_SIZE` = 20px、ウォームブラック）で表示する。
  選択は GUI の表示状態（プロジェクト状態ではない）で、タイム
  ラインのトラックヘッダーのクリックで切り替え、初期値は先頭
  トラック。判定は `edit::hit_track_header`（純粋関数）。
- 音量・パンの変更そのものは従来どおりコマンド経由で不変。

## 判断の記録（AI が決めた実装レベルの小判断）

- 「選択中トラック」の成立方法: 従来のアプリに選択の概念が
  なかったため、GUI の表示状態として最小限で導入した（ヘッダー
  クリックで選択、初期値は先頭トラック、プロジェクト状態・
  ダンプには含めない）。
- 大きな現在値の置き場: 選択中トラックのストリップ右側の空き
  領域に、音量とパンを1行（`+0.0 dB · C` 形式）で出す。
- 逸脱の記録: イシューの「触るファイル」にない `edit.rs` に
  選択判定の純粋関数 `hit_track_header` とそのテストを追加した。
  選択判定はポインタ→意味変換であり edit.rs の責務範囲内と
  判断した。逆に theme.rs は #23 の定数で足りたため無変更。
