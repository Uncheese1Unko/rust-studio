Issue #18 音声分析（合成の声らしい信号。実音声ではなく、F0=120Hz の
倍音列にフォルマント 730/1090/2440Hz の包絡を載せたもの）
生成: voice-like.wav を daw --pitch-demo で ±変換（エンジンと同じ経路）

基本周波数（自己相関で測定）:
  元:      F0 ≈ 120 Hz
  +7 半音: F0 ≈ 180 Hz（理論値 120*2^(7/12) = 180）
  -5 半音: F0 ≈  90 Hz（理論値 120*2^(-5/12) =  90）

フォルマント位置（倍音包絡のピーク、400-1500Hz 帯、目標 ≈730Hz）:
  元:      720 Hz
  +7 半音: 719 Hz（F0 が 1.5 倍になってもフォルマントは不動）
  -5 半音: 629 Hz（倍音間隔 90Hz のため 730 を挟む 630/720 のうち
           630 がピーク。1 倍音分以下のずれ）

長さ: 全て 1.50 秒（ピッチ変更で長さは変わらない）
レベル: 元 RMS 0.242 / +7 は 0.179 / -5 は 0.242。
  純サイン（狭帯域）では ADR-0009 の設定（フォルマント係数 1.0、
  compensate あり）で約 -8.5dB の低下が別途実測された（220Hz
  サイン +12: RMS 0.283 -> 0.108）。compensate なしでは低下しない
  が、ADR-0009 の確定設定を維持し、この特性は既知事項として記録する。

聴取による確認（アニメ声化していないか等）は音声出力デバイスの
ない環境のため実機未検証。ユーザー自身が ADR-0009 決定時に
実音声で聴取確認済み（声 x3 + ピアノ）。
