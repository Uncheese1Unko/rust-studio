## 実装内容

- **タイトル帯の定義**: `pianoroll::header_title_band(win_w)` を新設し、帯を「ラベル右端＋12 〜 ヒント左端−12」と定義した（ウィンドウ幅 960 のとき 112〜598 = 486px、#74 で指摘された帯幅と一致）。既存の `header_title_center_x` は同関数を使う形に整理し、計算結果は従来と同一。
- **タイトルの省略**: `ellipsize_title(text, band_width_px)` が、推定幅が帯幅を超えるタイトルを末尾 `…` で切り捨てる。帯幅 0 では `…` のみを返す。幅推定 `text_width_px` は文字種別係数（空白 0.32／小文字 0.56／大文字・数字 0.70／その他 ASCII 0.55／非 ASCII 1.0）×フォントサイズの保守的な近似。
- **ヒントの1行化**: 文言を "click place · drag move · Del delete · Esc close" に短縮（コロン除去）し、フォントを 11 → 10 に縮小した。推定幅はヒント域（中心 ±160px = 320px）に収まることを単体テストで固定した。
- 定数化: `HEADER_TITLE_FONT_SIZE = 12.0`、`HEADER_HINT_FONT_SIZE = 10.0`、`HEADER_HINT_TEXT`（値はタイトル 12／ヒント位置 右から 190 とも従来どおりで、変更は定数化のみ）。
