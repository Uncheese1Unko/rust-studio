## 実装の概要

- video-editor（#8/#9）の timeline.rs / edit.rs を DAW に適応し、
  意味論（レイアウト定数、ヒットテスト、ドラッグ／トリム、ダブル
  クリック配置、要素識別子）を同一に保った。DAW 側の差分は
  `place_clip_command` が配置先ソースを引数で受ける点と、波形表示の追加。
- 波形は純粋関数 `waveform_peaks`（インターリーブ入力の先頭チャンネル
  の絶対値ピークを柱ごとに集計）で事前計算し、クリップ矩形内に描く。
- 状態変更はすべて studio-core のコマンド経由（ADR-0004）。
