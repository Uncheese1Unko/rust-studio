## 判断の記録（AI が決めた実装レベルの小判断）

- 小節の数え方: プロジェクトのモデルにテンポがないため、ルーラーの
  1秒区切りを1小節として数える（`bar_at_ms`）。コード内コメントと
  本レポートに明記した。
- 小節チップの配置: ルーラー帯の中に置き、再生ヘッドの x に追随
  させる（左端はヘッダー幅でクランプ）。
- 角丸の近似: nannou の `rect` には角丸がないため、2枚の矩形と
  四隅の円で近似する `draw_rounded_rect` を導入した。
