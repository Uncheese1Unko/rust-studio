# 試験レポート： Issue #84 再生ヘッドが画面外に出たらタイムライン表示が追従する

- 日付: 2026-11-23
- 実行者: エージェント（デリバリーループ）
- 対象: 再生中に再生ヘッドが表示右端を超えたら、表示オフセットを
  ページ送りで進めて再生ヘッドを表示範囲内に保つ。F キーで追従の
  オン／オフを切り替え（既定オン）、ラップアラウンド時はオフセットを
  0 に戻す。追従状態は表示状態であり、プロジェクトには保存しない。
- 実装コミット: `fb782d9`（本体）、`cefe143`（レビュー対応）
- CI: 緑 https://github.com/Uncheese1Unko/rust-studio/actions/runs/45180632070
- 環境: Yoko の VM（Linux、ヘッドレス）。表示確認は Xvfb（:94）＋Mesa
  lavapipe（ソフトウェアレンダリング）。**実ディスプレイでの確認は未検証。**
  なお本 VM では xdotool と mesa-vulkan-drivers が欠けていたため、
  駆動前に apt で復旧した（過去レーンと同じ環境復旧）。
- テスト件数: 動画編集クレート 82 件 → 85 件（新規3件はいずれも
  timeline の追従計算）。ワークスペース全体 364 件 → 367 件。
  削除・弱体化なし。

## 設計

- 追従計算は `timeline::ViewScale::follow_playhead(playhead_ms, width, wrapped)`
  という GUI 非依存の純粋関数にした（既存の `zoom_at` / `scroll_by` と
  同じ設計）。右端超過時は表示幅（`visible_ms`）の整数倍だけオフセットを
  進めるページ送りで、フレーム毎の連続スクロールにはしない。範囲内と
  表示範囲より前（左）では不変（手動スクロール直後に表示を奪い返さない）。
  `wrapped` のときはオフセット 0。
- `main.rs` の `update()` で `advance_playhead` の直後に適用する。
  ラップアラウンドは「新しい再生ヘッド < 直前の再生ヘッド」で検出する
  （再生ヘッドの書き換えは `advance_playhead` のみで、減少は巻き戻り
  のときに限る）。オフセットが変わったときだけ、既存のホイール
  スクロールと同じ `scroll offset: N` 形式で標準出力に記録する。
- 追従オン／オフは Model の表示状態 `follow_playhead`（既定 true）。
  F キーの押下エッジで切り替え、`follow: on/off` を標準出力に記録する。
  リネーム／タイトル編集中も `prev_f_down` を同期し、編集終了直後の
  誤発を防ぐ（バグ #60 と同じパターン）。

## 受け入れ条件ごとの結果

### AC1: 追従オンで再生を続けると、右端超過のタイミングでオフセットが更新され再生ヘッドが常に表示範囲内に描かれる — ✅

- 実アプリ駆動（証拠 `evidence/issue-0084/drive.sh`、起動 A: 終端
  21,000ms のプロジェクト）で、再生ヘッドが 10,000ms を超えた時点で
  `scroll offset: 10000` が1回だけ記録され、スクリーンショット
  `02-followed.png` で再生ヘッド（赤線）が表示範囲内に戻っている
  ことを画素で確認した（赤画素数: 初期 152 → 追従後 152）。

### AC2: 追従はページ送りで、フレーム毎に滑らかにスクロールし続けない — ✅

- 駆動ログで、右端超過前は `scroll offset:` 行が0件、超過時に
  ちょうど1件だけ増えることを確認した。純粋関数も「右端超過時に
  表示幅の整数倍だけ進める」実装で、単体テストで固定した。

### AC3: F キーでオン／オフを切り替えられ、オフの間はオフセットが変わらない — ✅

- 駆動で F を押し `follow: off` → `follow: on` → `follow: off` の
  切り替えログを確認。オフのまま 13 秒間（20,000ms の右端超過と
  21,000ms のラップアラウンドを含む）再生を続けても
  `scroll offset:` 行は増えなかった（1件のまま）。

### AC4: ラップアラウンド時はオフセットも 0 に戻り再生ヘッドが見える — ✅

- 起動 B（終端 11,000ms）で `scroll offset: 10000` の後に
  `scroll offset: 0` が記録され、スクリーンショット `04-wrapped.png`
  で再生ヘッドが左寄りに見えていることを確認した。

### AC5: 追従計算が純粋関数として単体テストで固められている — ✅

- `timeline.rs` の新規テスト3件: `follow_playhead_pages_forward_past_right_edge`
  （右端ちょうどは不変／超過でページ送り／複数ページ／ズーム2での
  ページ幅）、`follow_playhead_keeps_offset_when_playhead_in_view_or_before`
  （範囲内・範囲より前は不変）、`follow_playhead_resets_offset_on_wrap`
  （ラップ時は 0）。`cargo test -p video-editor` で通過。

### AC6: 既存の操作が従来どおり動く — ✅

- `./scripts/verify.sh` 全通過（fmt / clippy / ワークスペース全
  367 テスト）。ホイールスクロール・ズーム・ドラッグの経路には
