# 試験レポート: Issue #100 ステム音声からメロディ（ノート列）を抽出できる

- 日付: 2026-11-26
- イシュー: #100（EPIC #97 の PBI）
- 結論: **受け入れ条件を満たした。** 既知メロディのテスト WAV では
  実ステム（Demucs 分離後）から元の音列 [69, 72, 76, 81] を完全抽出し、
  開始誤差は最大 14ms（許容 ±100ms）だった。2パートミックスでは
  分離品質の限界（後述）により部分一致に留まったことも正直に記録する。
- テスト件数: ベースライン 519 件 → 527 件（新規8件: pitch 6件、
  separation 統合 2件）。削除・弱体化なし。
- 環境: Yoko の VM（Linux、ヘッドレス）。

## 設計とパラメータ

ピッチ追跡は #98 の調査試作（`evidence/issue-0098/pitch-proto-main.rs`）を
土台に `apps/daw/src/pitch.rs` へ実装した。自己相関による単旋律追跡で、
外部クレートは追加していない。パラメータは試作で実証済みの値を定数として
明示する:

- 窓長 2048 サンプル、ホップ 512 サンプル（44.1kHz で約 11.6ms）
- 探索周波数域 50〜1200 Hz
- 無音しきい値: フレーム RMS < 0.02 は無音高
- 周期性しきい値: 正規化自己相関の最大値 < 0.5 は無音高
- 最小ノート長: 同一音高 4 フレーム（約 46ms ＋ 窓）
- 欠落許容: 同一音高の区間内で 1 フレームまでの無音高を吸収
- ベロシティ: 区間内のピークフレーム RMS から
  `round(127 × min(1, peak_rms / 0.5))`（1..=127 にクランプ）で決定的に導出

前提と限界（正直な扱い）: 単旋律のみ。和音・複数音の同時追跡はしない。
ドラム等の音高の定まらないステム、無音区間ではノートを作らない
（空のノート列が正しい結果）。分離後のステムに他パートの漏れがある場合、
漏れの音高を拾うことがある（実ステムでの答え合わせで実測して記録する）。

統合（ADR-0024 の最終形）: 分離パイプライン（`separation.rs`）が
各ステムをデコードして抽出まで行い、音高が取れたステムは
ノートクリップ（`source` は空、ノートは `AddNote` コマンド経由）として、
取れなかったステムは従来どおり波形クリップとして、同じ原子的適用
（`commit_replacement`）でプロジェクトへ載せる。

## 受け入れ条件ごとの結果

### 1. 既知メロディの音高列・開始が一致する — ✅（実ステムで確認）

- 単体テスト `extracts_known_melody_pitches_and_onsets`: 合成メロディ
  （A4→C5→E5→A5、各 500ms、減衰エンベロープ＋倍音）から
  音高列 [69, 72, 76, 81] が一致し、開始は ±100ms 以内、長さは
  500±200ms 以内。
- 実ステムでの答え合わせ（`daw --separate` で実際の Demucs 分離→抽出）:
  - **メロディのみのテスト WAV**: `other` ステムから
    **(69, 開始 0ms), (72, 487ms), (76, 986ms), (81, 1497ms)** を抽出。
    元の音列 [69, 72, 76, 81] と完全一致し、開始誤差は最大 **14ms**
    （期待 0/500/1000/1500ms）。長さは 476/487/487/464ms（元は各 500ms）。
    他の3ステムはノートなし（波形クリップ）で、正しい扱い。
  - **2パートミックス（メロディ＋Cメジャーのパッド）**: Demucs が
    ほぼ全エネルギーを `other` へ寄せた（RMS: other 0.3003、
    vocals 0.0035、drums 0.0004、bass 0.0003。実音楽で学習した
    モデルに合成パッド＋正弦波メロディは分離しきれなかった）。
    `other` の抽出は (69, 34ms)、(76, 986ms)、(81, 1486ms) を回収
    したが、C5（72）の区間はパッドの漏れが勝ち、50/53 の短い
    偽ノート（46ms 級）が出た。**ミックスでは部分一致に留まる**こと
    を限界として記録する（証拠: `evidence/issue-0100/notes-summary.txt`）。

### 2. 無音・無音高ステムではノートを作らない — ✅

単体テスト `silence_yields_no_notes`（無音 1 秒 → 空）と
`noise_yields_no_notes`（決定的疑似ノイズ 1 秒 → 空）で確認。
実ステムでも、エネルギーのほぼ無い vocals／drums／bass は
ノート列が空になり波形クリップとして置かれた（上記サマリ）。

### 3. ノートはモデルの不変条件を満たし、コマンド経由で追加される — ✅

抽出ノートは `AddNote` コマンド経由でのみ追加され、コアの検証
（pitch／velocity 0..=127、クリップ範囲内）を通る。単体テスト
`notes_satisfy_model_invariants`（抽出側の不変条件）と
`apply_stems_with_notes_adds_note_clip`（ノートクリップ化＋
無音高ステムは波形のまま）、`apply_stems_rejects_notes_outside_the_clip`
（範囲外ノートは取り込み全体が失敗し、プロジェクト・履歴とも不変）
で確認した。

### 4. ベロシティは決定的に導かれる — ✅

単体テスト `extraction_is_deterministic`（同一入力で2回の抽出結果が
完全一致）で確認。ベロシティの導出式は上記のとおり定数化した。
実ステムでもメロディ4音のベロシティは 114〜116 と安定していた。
