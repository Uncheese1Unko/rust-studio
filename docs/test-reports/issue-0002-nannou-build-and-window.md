### `unwrap()` について（指摘3への回答）

`model()` のウィンドウ生成と `view()` のフレーム提出に `unwrap()` がある。
本アプリは「環境で描画できるか」を表面化するための smoke アプリであり、
失敗時にパニックで loud に落ちるのは調査目的に適うため、この PBI では
意図的に残す。本格的な GUI を作る後続 PBI では、エラーは処理して
ユーザーに見える形で扱うこと。
