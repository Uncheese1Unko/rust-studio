# 試験レポート: #93 ディレイとリバーブが音に効く（時間系エフェクトの DSP）

## 実装内容

`apps/daw/src/effects.rs` に時間系 DSP を追加した（依存クレート追加なし）。

- ディレイ: チャンネルごとの循環バッファ。出力 = ドライ + mix × ウェット、遅延入力 = 入力 + feedback × ウェット。遅延サンプル数は time_ms × サンプルレートから導出。
- リバーブ: Schroeder/Freeverb 系。チャンネルごとにコム8本（遅延量 1116〜1617、44.1kHz 基準をサンプルレート比でスケーリング、右は +23 のステレオ広がり）の並列 → オールパス4本（556/441/341/225、ゲイン 0.5）の直列。コムのループ内に一次ローパス（ダンピング固定 0.2）。decay 0.0..=1.0 はコムフィードバック 0.7..=0.98 へ線形写像。コム入力ゲインは 0.2（下記「実装中に調整した点」）。
- DSP 状態は `process_chain` 呼び出しごとに生成する（#92 の ADR-0023 どおり）。同じ入力には常に同じ出力（決定的）。

## TDD の記録（red）

- 先に書いたテスト5件が失敗した: `delay_produces_echoes_at_configured_time`、`chain_composes_eq_into_delay_echoes`、`reverb_extends_impulse_tail`（以上 effects 単体）、`delay_echoes_appear_in_rendered_mix`、`reverb_tail_appears_in_rendered_mix`（render_mix 経由）。#92 で固定していた素通りテストは「効く」側のテストへ書き換えた。
- 実装中に調整した点: コム入力ゲインを Freeverb 本家の 0.015 のままにすると尾が小さく、900–1000ms のピークが 0.000995 で -60dB の閾値に届かなかった。0.2 へ引き上げて 0.00398（約4倍の余裕）を確保した（定数コメントにも経緯を明記）。

## 実測検証（測定値）

単体（DSP 直接、インパルス入力）:

| 測定 | 設定 | 実測 |
|---|---|---|
| ディレイ エコー | time 200ms / fb 0.5 / mix 0.5 | 200ms: **0.5**、400ms: **0.25**、600ms: **0.125**（±0.02）、100ms は無音、ドライ保存 |
| リバーブ尾ピーク（900–1000ms） | decay 0.8 / mix 1.0 | **0.00398**（-60dB = 0.001 を上回る） |
| リバーブ尾ピーク（区間別） | 同上 | 100–300ms: 0.0993、300–600ms: 0.0240、600–1000ms: 0.00656、1500–2000ms: 0.000651 |
| リバーブ -40dB 到達（Schroeder 後方積分） | 同上 | **1325.7ms**（条件: 500ms 超） |
| decay の大小比較 | decay 0.2 の 900–1000ms ピーク | decay 0.8 より小さい（尾が短い）ことを assert |

CLI（`daw --export-wav`、プロジェクト音量 0.8 のため絶対値は 0.8 倍、スクリプトと入力は `evidence/issue-0093/`）:

- ディレイ: dry 0.8000、echo@200ms **0.4000**、@400ms **0.2000**、@600ms **0.1000**、@100ms は 0（比は 0.5 / 0.25 / 0.125 で理論どおり）。
- リバーブ: ピーク 100–300ms 0.0794、300–600ms 0.0192、600–1000ms 0.0052、900–1000ms 0.00317、1500–2000ms 0.00052。Schroeder -40dB 到達は **1325.7ms**（レビュアーの独立測定 1325.8ms と一致）。

チェーン順序の確認方法（着手時注記で是正）: EQ・ディレイ・リバーブはいずれも線形時不変系で直列接続は可換なため、「順序で出力が異なる」は条件として成立しない。代わりに構成測定で確認した: [EQ → Delay] のエコー位置（195–215ms）のピークが EQ 単体応答のピーク × mix（0.5）と許容範囲内で一致し、チェーン出力は EQ 単体とも Delay 単体とも異なる。

バイパス等価: Delay は mix=0 とバイパスの両方で入力とサンプル単位一致、Reverb は render_mix 経由でバイパス後にドライと一致。決定的であることも両系で assert した。
