# Issue #69 試験レポート: ピアノロールでノートを配置・移動・削除できる

- 対象イシュー: #69（EPIC #66 [M3] の子）
- 前提: ADR-0016（コマンド MoveNote / RemoveNote は本 PBI の担当）
- 実装コミット: `b101ce9`（ピアノロールでノートを配置・移動・削除できる）、修正コミット `dbd0a68`（レビュー指摘の修正）

## 実施内容

### コマンド（studio-core）と MCP 公開

- `MoveNote { clip_id, note_index, new_pitch, new_start_ms }` と
  `RemoveNote { clip_id, note_index }` を追加。検証は値域
  （音高 0–127、開始 0 以上）→ クリップ存在 → インデックス範囲 →
  範囲適合（減算形で比較し、巨大な開始位置でもオーバーフロー
  しない）の順で、失敗時は状態不変。MoveNote は長さとベロシティを
  保つ。
- MCP に `move_note` / `remove_note` ツールを公開（tools/list の
  一覧テストと tools/call の適用テストで確認）。

### ピアノロール（apps/daw/src/pianoroll.rs、新規）

- GUI 非依存モジュールにレイアウト計算とヒットテストを切り出した
  （timeline モジュールの前例）。座標は左上原点ピクセル、横軸は
  クリップの尺をグリッド幅に写し、縦軸は 25 行（2オクターブ＋1、
  開いたときにノートが収まる中心、空なら C4 中心。スクロールなし）。
- 配置: 空きグリッドのクリックで `AddNote`（既定の長さ 500ms、
  ベロシティ 100、右端では開始を切り詰め）。既存ノートの上では
  配置しない。
- 移動: ノートを掴んでドラッグ。掴んだ位置と元の値を保持し、
  移動量で `MoveNote` を作る（タイムラインの Drag と同じ考え方）。
  音高は表示範囲、開始はクリップに収まる範囲にクランプ。
- ヒットテストは重なりで大きいインデックス（上に描かれる方）を
  優先する。

### 画面と操作の接続（main.rs）

- 導線: タイムラインのクリップをダブルクリックで開く。対象は
  ノートクリップ、素材なしクリップ、楽器のあるトラックの
  クリップに限る（波形クリップを誤ってノートクリップ化しない
  ための実装判断）。ダブルクリック判定は専用の ClickTracker。
- 開いている間は画面モードを切り替え、ポインタはすべてロール側で
  捌く。ドラッグは #31 と同じジェスチャ方式（開始時にスナップ
  ショット、移動中は transient 適用、解放時に履歴へ記録）。
  ドラッグ中の再押下は無視するガードを入れた（押下の跳ね返りで
  配置が走るのを防ぐ。実駆動で再現したための対策）。
- 削除: ノートを選択（掴んだ時点で選択される）して Delete /
  Backspace。Esc で閉じる（ループ解除より優先）。
- Undo/Redo: 履歴が動いたらロールのドラッグと選択を打ち切り、
  対象クリップが消えていたらロールを閉じる。ジェスチャ中の
  Undo/Redo は #31 の `apply_history_key` の対象にロール側の
  スナップショットも加えた。
- 描画はテーマ（ADR-0012）に従い、パネルラベル「06 PIANO ROLL」
  を追加。ノートはティール、選択中と発音中だけホットピンク。
  鍵盤列には C の行に音名、拍の縦線はプロジェクトの BPM 基準。

## 受け入れ条件との対応

1. ✅ クリックで配置でき、ダンプに反映される — 駆動の
   「after note add」ダンプと保存ファイルで確認。要素の観測は
   既存のマーカー付きダンプ（ADR-0005 の観測経路）に従った。
2. ✅ ドラッグで移動（音高と開始）でき、ダンプと再生に反映される
   — 駆動の「after note move」ダンプで確認。再生は #68 の
   render_mix がノートを読むため、移動したノートがそのまま鳴る
   （単体テストで担保）。
3. ✅ 選んで削除でき、ダンプに反映される — 駆動の
   「after note remove」ダンプで確認。
4. ✅ 編集がすべてコマンド層経由で Undo/Redo で戻せる — 駆動で
   配置・移動・削除の後に Ctrl+Z を確認。すべての変更は
   Command の適用（ドラッグは transient＋ジェスチャ記録）。

## 残件・申し送り

- ベロシティ編集、複数選択、クオンタイズ、表示範囲のスクロールは
  イシューのスコープ外（将来の拡張候補）。
- 波形クリップ（素材あり・楽器なしトラック）はダブルクリックで
  開けない。必要になれば導線の条件を広げる。
- 実ディスプレイでの操作感は未検証（従来どおり）。
