## 実装の概要

- トランスポートパネルを新設した（ミキサーの下、全面幅のペール
  クリーム面＋角丸）。`01 TRANSPORT` ラベルは、このパネルを作る
  本イシューで初めて描画した（#23 では定数だけ用意）。
- 進行度: 現在地を `BAR n · BEAT m` の大きな数字（20px）＋横バー
  （溝はサンド、進んだ分はピンク）＋秒数で常時表示する。
- レベルメーター: 再生位置の直後 100ms のミックスを `render_mix`
  でレンダリングし（読み取り専用、音声処理は無変更）、ピークを
  取って横バーで示す。通常はティール、ピーク付近（-3dB 以上）
  だけホットピンク。dB 値も併記する。再計算は再生位置が 50ms
  以上動いたときだけ（間引き）。
- 純粋関数を `audio.rs`（`peak_of` / `peak_db` / `is_peak_level`、
  定数 `PEAK_LEVEL_DB` / `METER_FLOOR_DB`）と `timeline.rs`
  （`beat_at_ms`）に追加した。デコード済み音声は波形と同じ作法で
  Model に保持し、プロジェクト再読込時に再計算する。

## 判断の記録（AI が決めた実装レベルの小判断）

- トランスポートパネルの置き場: 既存レイアウト（ルーラー／
  トラック／ミキサー／サンプラー）を崩さないため、ミキサーの
  下の空き領域に独立パネルとして置いた。再生位置の小節チップ
  （#24）はルーラー帯に残置した。
- 拍の数え方: テンポがモデルにないため、#24 の判断（1秒＝
  1小節）に合わせ1小節＝4拍（1拍＝250ms）とした。
- ピークの窓と間引き: 再生位置の直後 100ms を窓とし、50ms
  以上の移動で再計算する。サンプラーのボイスは `render` が
  状態を消費するため対象外とし、ミックス（プロジェクトの
  レンダリング）のピークのみを対象にした。
