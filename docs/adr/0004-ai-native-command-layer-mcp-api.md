# ADR-0004: AI ネイティブ：コマンド層＋MCP＋API

- ステータス: 採用
- 日付: 2026-11-21
- 決定者: ユーザー（MCP サーバーと API を持ち、指示するとそのとおりに動く
  作りにする指定）

## 背景

「こうして」と指示するとアプリがそのとおりに動く、AI ネイティブな
編集ソフトにしたい。GUI 操作しかないアプリは、AI が操作できても
画面のピクセル経由でしか触れず、不安定で検証もできない。

## 決定

- 編集操作はすべて `studio-core` の**コマンド**として定義し、状態変更は
  コマンド適用の形でのみ行う（単一の変更経路）。
- コマンドは JSON にシリアライズ可能にする。
- **MCP サーバー**がコマンドを tools として公開する（AI への指示経路）。
- **HTTP/JSON API** がコマンド実行とプロジェクト状態の全量ダンプを提供する
  （検証と computer use テストの経路）。
- GUI も同じコマンドを実行する。GUI だけができる操作を作らない。

## 結果

AI の指示、GUI 操作、自動テストがすべて同じ意味論で動く。
undo/redo と操作ログはコマンド列の上に実装できる。
制約として、新機能はまずコマンドとして設計する必要があり、GUI 先行の
場当たり実装ができなくなる（それが狙いでもある）。
