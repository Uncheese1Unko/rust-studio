# ADR-0006: ohta 式ハーネスを採用し、設計判断は人間が持つ

- ステータス: 採用
- 日付: 2026-11-21
- 決定者: ユーザー（ohta-rh 氏のリポジトリの方法に倣う指定＋判断記録の方針）

## 背景

ohta-rh 氏の x-modoki-v2 / insta-modoki は、EPIC→PBI の起票作法、
デリバリーループ、常時 TDD、独立コードレビュー、証拠付き試験レポート、
ADR による判断記録を `.claude/rules/` と `.claude/agents/` に固定した
AI 駆動開発ハーネスを持つ。ユーザーはこの方法に倣うよう指定した。

ただし ohta 方式には「ユーザーに聞かない。判断はエージェントが決めて
ADR に書く」という原則があり、これはユーザーの一貫した方針
（設計判断は人間が行い、理由付きで記録する）と衝突する。

## 決定

ハーネスの骨格（起票作法、ループ、TDD、独立レビュー、完了の定義、
試験レポート、ADR）を採用する。判断ポリシーだけ次のように変える。

- **設計判断**（アーキテクチャ、技術選定、プロダクトの振る舞い）：
  AI は決めない。`needs-decision` で止まり、選択肢と推奨を人間に渡す。
- **実装レベルの小判断**：AI が決めてよい。ADR に記録し（決定者：
  エージェント）、最終報告で明示する。
- バグ対応の「止まらず直し切る」は、設計判断が絡まない範囲で採用する。

## 結果

無人で回る範囲と、人間の判断が溜まる範囲の境界が明示される。
ループは設計判断のたびに止まるため完全無人にはならないが、それが
このプロジェクトの目的（人間の判断を蓄積して改善していく）に合う。
