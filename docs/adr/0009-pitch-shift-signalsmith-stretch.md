# ADR-0009: 性質を保つピッチシフトは Signalsmith Stretch を採用する

- ステータス: 採用
- 日付: 2026-11-21
- 決定者: ユーザー（声素材の聴き比べで Signalsmith が最も自然と判定し、
  採用を指示した）。エージェントは調査と測定を担当した
- 関連: ADR-0007（本 ADR はその「方式は調査後に決める」を満たす。ADR-0007 は有効のまま）、
  調査レポート `docs/test-reports/issue-0017-pitch-method-research.md`、Issue #17

## 背景

ADR-0007 は、声などの性質（フォルマント）を保ったピッチ変更をネイティブ機能とし、
方式は調査してから決めると定めた。Issue #17 で、声3本＋ピアノ1本を ±4/+7/+12/-7
半音で処理し、方式ごとにフォルマント移動率（α、1.00 が保持）を測り、人間が聴いた。

## 決定

- ピッチシフト／タイムストレッチの実装に **Signalsmith Stretch**
  （`signalsmith-stretch` crate、MIT）を使う。フォルマント保持は
  `set_formant_factor(1.0, true)` で有効にする。
- 処理はコアに入れない（architecture.md の「メディア処理」）。コアは
  ピッチ量などのパラメータだけを持ち、処理はアプリ側のメディア層で行う。
- 実装 PBI（DAW のピッチ変更。#19 など）は本 ADR に従う。

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| Signalsmith Stretch（採用） | 聴感で最も自然（人間）。声3本の |α-1| 平均が上げ 0.06／下げ 0.06 と最小。MIT。リアルタイム前提の設計 | C++ 本体を FFI で使う。Windows のビルドで bindgen 用の libclang が要る。純 Rust 移植は未確認 |
| Rubber Band | 明示的なフォルマント保持オプション | **R3 は未検証**（ffmpeg 経由は R2 のみ）。R2 では +7 以上で崩れる素材あり（上げ 0.25）。GPLv2／商用の配布判断が要る |
| SoundTouch | 採用実績が広い | 保持機能がなく ADR-0007 の要件を満たさない（机上調査） |
| 自前フェーズボコーダ＋包絡保持 | 依存なし | 実装負荷が大きく、既製品の保持機能に劣る |

## 結果

- ライセンス判断（GPL／商用）が不要になる。
- ビルド環境に libclang（と C++ コンパイラ）が要る。CI とセットアップ手順に
  反映する（実装 PBI の受け入れ条件に含める）。
- 声が短い素材での代理指標と聴取1回に基づく。覆す条件: 実装後に別素材
  （混在音源、打楽器）で品質問題が出た場合、または Rubber Band R3 が
  明確に優れると検証された場合は、本 ADR を supersede する。
