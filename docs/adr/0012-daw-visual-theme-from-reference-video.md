# ADR-0012: DAW のビジュアルテーマに参照動画ベースのライトテーマを採用する

- ステータス: 採用
- 日付: 2026-11-21
- 決定者: ユーザー
- 関連: ADR-0002（Rust + nannou）、イシュー #20

## 背景

DAW の GUI は #13〜#16・#18・#19 で機能が揃ったが、見た目は暗色の
仮テーマのままで、色も描画コードにリテラルで散らばっている。ユーザーから
「こういう感じにしたい」参照動画が指定された：Emocute「Kawaii BASS
[Riddim]」（https://youtu.be/KFA9YZselQ4?si=msWmGCSWLAVAcz-l）の、
楽曲解析を可視化するダッシュボード映像。要素分解は
`docs/design/daw-visual-design.md` にある。

## 決定

DAW のビジュアルテーマとして、参照動画の作りを採用する。

- 基調はほぼ白に近いクリームのライトテーマ。フラットで影・グラデーション
  なし、面の区別は淡い色差と細線。
- アクセントはホットピンク1色に限定し、「現在の状態」だけに使う。副色は
  ティール／ミント。文字とプレイヘッドは黒。
- パネルには連番＋大文字の小ラベルを付け、階層は色ではなく現在値の
  文字サイズで作る。
- 具体的な色値・質感・適用範囲はデザイン文書
  `docs/design/daw-visual-design.md` を唯一の出所とする。
- 適用範囲は DAW のみ。色定数は `apps/daw` 内のテーマモジュールに集約し、
  studio-core には置かない。

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| 参照動画ベースのライトテーマ（採用） | ユーザーの「かっこいい」の基準が具体的で、比較・検証できる。既存の暗色 DAW 群と差別化できる | 一般的な DAW の暗色慣習と逆で、長時間作業での見え方は実機で確かめる必要がある |
| 現状のダークテーマを磨く | DAW の慣習どおりで無難。変更量が小さい | ユーザーが基準を示したのに応えていない。色リテラルの散在は解消しない |
| 動画編集と共通のテーマ基盤を先に作る | 2アプリで見た目が揃う | 動画編集への展開は未定。コアの GUI 非依存（アーキテクチャルール）に触れる。先行投資が大きい |

## 結果

- DAW の画面はデザイン文書に沿って作り替え、参照と並べたスクリーン
  ショットで比較できるようになる（実装 PBI 側で検証）。
- 動画編集のテーマは未定のまま残る。DAW の結果を見て別途判断する。
- 覆す条件：実機で見た目・視認性の問題が出た場合、またはユーザーが
  別の参照を示した場合。そのときは新 ADR で supersede する。
