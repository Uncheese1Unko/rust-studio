# ADR-0005: computer use でテストできる作りにする

- ステータス: 採用
- 日付: 2026-11-21
- 決定者: ユーザー（computer use でテストできる作りにする指定）

## 背景

AI エージェントが画面を操作してテストする（computer use）には、画面の
状態が機械から観測でき、操作対象が安定して特定できる必要がある。

## 決定

- UI 要素には安定した識別子（名前）を持たせる。位置や見た目だけに
  依存するテストを作らない。
- HTTP API がプロジェクト状態の全量ダンプを返す。画面で観測できる
  受け入れ条件は、状態ダンプでも同じ内容が観測できることを必須とする。
- 試験レポートにはスクリーンショット等の証拠を残す（ohta 式ハーネスの
  完了の定義に倣う）。
- 時刻・乱数に依存する振る舞いはテストで固定できるよう注入可能にする。

## 結果

画面操作テストと API テストが相互の裏付けになる。UI 実装には
識別子付けの手間が常時かかる。
