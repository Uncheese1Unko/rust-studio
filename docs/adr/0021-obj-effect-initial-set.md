# ADR-0021: `obj.effect` の初期セットは「色調補正・単色化・ぼかし・色反転」とする

- ステータス: 採用
- 日付: 2026-11-24
- 決定者: エージェント（実装レベルの判断。ADR-0019 判断点4が「初期集合の範囲は #83 の設計時に決める」と委ねた事項。#83 レビュー round 1 の Minor 指摘を受け、判断を行った変更とあわせて記録する）
- 関連: ADR-0006（設計判断は人間、実装レベルの小判断はエージェントが記録）、ADR-0019（AviUtl Lua 互換の範囲・方式 A）、Issue #83

## 背景

ADR-0019 は、`obj.effect` を「本アプリが再実装した名前付き効果の
集合に対してだけ動くもの」とし、初期集合の範囲は #83 の設計時に
決めるとした。未知の効果名は無言で無視せず明示的なエラーにする
ことも同 ADR で決まっている。

初期集合の選定では、ExEdit の組み込み効果のうち、(1) 本アプリの
CPU 合成経路（RGBA バッファへの画素演算）だけで完結し、他の
オブジェクトやフレーム間状態を必要としないこと、(2) 配布
スクリプトでの利用が一般的で、効果名とパラメータの意味を
lua.txt の記述から一意に再実装できること、を基準にした。

## 決定

**初期セットは「色調補正」「単色化」「ぼかし」「色反転」の4つ
とする。** いずれも対象バッファへの画素演算のみで完結する。
既知の効果に対する未知パラメータは無視する（ExEdit 側でも
パラメータ追加の互換が保たれてきたため）。集合外の効果名と、
引数なしの `obj.effect()`（後続エフェクトの実行）は明示的な
実行時エラーにする。

対応範囲の一覧は `docs/aviutl-compat.md` に集約し、本 ADR は
選定の判断だけを保持する。集合の追加は、実スクリプトでの需要と
再実装可能性を確認したうえで、別 PBI で本 ADR を supersede
せずに compat ドキュメントと合わせて更新する（集合の追加は
後方互換な拡張であり、本決定の骨子＝「再実装した集合に対して
だけ動かし、未知は明示エラー」は変えない）。
