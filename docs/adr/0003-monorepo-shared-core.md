# ADR-0003: モノレポ：共通コア＋アプリ2本

- ステータス: 採用
- 日付: 2026-11-21
- 決定者: エージェント（構成案。ユーザーの「別にもう1つ作りたい」＝2アプリを
  1つの取り組みとして作る指示に基づく）

## 背景

動画編集ソフトと DAW は、タイムライン・トラック・クリップ・再生位置という
中核モデルを共有する。別リポジトリにするとモデルと AI インターフェースが
二重実装になり、片方だけ進化して乖離する。

## 決定

1つの Cargo ワークスペース（モノレポ）に置く。

- `crates/studio-core`：モデル＋コマンド層（GUI・メディア・ネットワーク非依存）
- `apps/video-editor`：AviUtl 風の動画編集ソフト
- `apps/daw`：Reaper 風の DAW

## 結果

モデルとコマンド層が1つになり、MCP/API の実装も共有できる。
アプリ固有のメディア処理はアプリ側に閉じる（architecture ルール）。
