# ADR-0022: MIDI 取り込みの既定楽器として組み込みシンセ（Instrument::Synth）を割り当てる

- ステータス: 採用
- 日付: 2026-11-25
- 決定者: エージェント（Issue #89 の実装レベルの判断。ユーザーの依頼「MIDI を読み込んで音を鳴らせるようにして」の範囲内で、ADR-0016 の「バリアント追加で受ける」拡張点に沿う）
- 関連: ADR-0016（楽器はトラック単位、バリアント追加が拡張点）、ADR-0018（音色コレクションと実効楽器）、ADR-0005（状態ダンプは画面で観測できるものと一致する）

## 背景

MIDI 取り込み（Issue #70）はノートを持つトラックを作るが楽器を割り当てない。`render_mix` は実効楽器が Sampler でも Plugin でもないトラックのノートを鳴らさないため、取り込んだプロジェクトは、利用者が TONES パネルで音色を手作業で割り当てるまで完全な無音になる（Issue #89 で実測: 取り込み成功・2トラック5ノートのプロジェクトの WAV 書き出しが 1.60 秒・ピーク 0）。

「読み込んで鳴らす」という #68・#70 の狙いを利用者体験として成立させるには、取り込み時点で「追加操作なしで鳴る楽器」が要る。鳴らし方には次の制約がある。

- 状態ダンプ（JSON）が画面で観測できるものと一致すること（ADR-0005）。ダンプ上は楽器なしなのに音が出る、という隠れた規則は持てない。
- 外部ファイル素材に依存しないこと。リポジトリには全環境で使える組み込み音声素材が無く、サンプラーの `source` に実在しないパスを書くと、音声マップに載らない経路（GUI／API／別マシン）で再び無音化する。
- 後からサンプラー音色や Vital（プラグイン）へ差し替えられること（既存の `SetTrackInstrument`／音色の仕組みを妨げない）。

## 決定

**`Instrument` に `Synth { waveform: SynthWaveform }` バリアントを足し、MIDI 取り込みは各トラックへ `Instrument::default_synth()`（三角波）を `SetTrackInstrument` コマンドで割り当てる。**

- `SynthWaveform` は Sine／Triangle／Square／Sawtooth の4種。既定は三角波（倍音が少なく音高が分かりやすい）。
- `render_mix` は Synth トラックについて、ノートの絶対音高から周波数を導き（440 × 2^((pitch−69)/12)）、波形を手続き的に生成して発音する（純粋関数 `synth_sample`、5ms アタック＋末尾 10ms リリースのエンベロープ付き）。外部素材も事前レンダリングも要らない。
- 割り当ては取り込みのコマンド列の一部として適用されるため、状態ダンプには `instrument: {"type": "synth", "waveform": "triangle"}` と正直に現れ、Undo 1回で割り当てごと取り込み前に戻る。
- 差し替えは従来どおり `SetTrackInstrument`／`SetTrackTone` で行う。実効楽器の解決（ADR-0018）はそのまま効く。

## 検討した選択肢

| 選択肢 | 長所 | 短所 |
|---|---|---|
| **Synth バリアント＋取り込み時に明示割り当て（採用）** | ダンプに鳴る理由がそのまま現れる。素材ファイル不要で全経路（CLI／GUI／API／MCP）で同じく鳴る。差し替え機構がそのまま使える | `Instrument` のバリアントが1つ増え、表示側の match に腕が要る |
| Sampler に組み込み素材を割り当てる | 既存の発音経路をそのまま使える | 組み込み素材の実体が無い。生成した WAV へのパスを状態に書くと、プロジェクトファイルの置き場所や環境が変わった途端に再び無音化し、ダンプも実在しない素材を指すことになる |
| render_mix が「楽器なし」を既定シンセとして扱う（フォールバック） | モデル変更なしで鳴る | ダンプは `instrument: null` のまま音が出るため ADR-0005 に反する。指紋・事前レンダリング・GUI 表示など実効楽器を見る全箇所に同じ隠れ規則を複製することになる |
| 取り込み時に音色（Project.tones）を作って割り当てる | 名前付きで管理できる | 取り込みのたびにコレクションへ既定音色が増える。トラック直接の割り当てで十分な場面にコレクションの管理コストを持ち込む |

## 結果

- MIDI を読み込むだけで、GUI 再生でも WAV 書き出しでも音が鳴る。鳴っている理由はプロジェクトの状態そのものに書かれている。
- 制約: シンセの音色は波形4種のみで、ADSR 等の細部は持たない（必要になったら Synth のフィールド追加で受ける）。ライブ演奏サンプラー（`apps/daw/src/sampler.rs`）は対象外で、従来どおり素材ベースのまま。
- 対象外として残るもの: ピアノロールで新規トラックにノートを置く場合の自動割り当ては Issue #90 で追う（GUI のジェスチャ／Undo モデルと絡むため分離した）。既に `instrument: null` で保存されたプロジェクトの自動修復はしない。
- 覆す条件: 組み込み素材（サンプル集）を製品に同梱する判断が別途なされたら、既定楽器をそちらへ寄せることを再検討する。
