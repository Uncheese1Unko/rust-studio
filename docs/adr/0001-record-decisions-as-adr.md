# ADR-0001: 判断を ADR に記録する

- ステータス: 採用
- 日付: 2026-11-21
- 決定者: ユーザー（判断を理由付きで永続記録する方針）

## 背景

AI 駆動開発では、判断の経緯が見えないと次のセッションが同じ論点を蒸し返す。
ユーザーは「自分が判断をするたび、その理由が残り続けるようにしたい」と
一貫して求めている。

## 決定

アーキテクチャ・技術・横断ルールに関する判断は `docs/adr/` に ADR として
記録する。判断をした変更と同じコミットで足し、採用済みは編集せず
supersede で覆す。決定者（人間／エージェント）を明記する。

## 結果

判断の履歴がリポジトリに蓄積され、AI の前提（コンテキスト）になる。
記録の手間が増えるが、蒸し返しと独断の両方を防げる。
