# Code Review — 独立レビュー

- コードを変える PBI はすべて、push の前に独立レビューを受ける。
- レビュアーは新規の `code-reviewer` サブエージェント（read-only）。
  渡すのは**イシュー番号と diff 範囲だけ**。実装者の要約・推論・言い訳は渡さない。
- 指摘は実装者が1つずつ自分で確かめる。本物はテスト先行で直し、誤りは
  根拠（再現結果、該当コード）を付けて退ける。
- コードが変わったら、新しいレビュアーでもう一度。`APPROVE` が出るまで回す。
- 結果は試験レポートの「コードレビュー」に残す。
- 3ラウンド通らなければ、最後の緑の状態に戻して変更を小さく割り直す。
