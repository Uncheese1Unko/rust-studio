# Definition of Done — 完了の定義

PBI 本文の末尾に、以下の項目をそのままチェックボックスで貼る。項目を減らさない、
言い換えない。全部にチェックが入ったときだけ close できる。

- [ ] 受け入れ条件を全部、書いてある確認方法で1つずつ確かめた
- [ ] TDD で実装した（振る舞いごとにテストを先に書き、期待した理由で落ちるのを
      見てから実装した。落ちた出力を試験レポートの「TDD の記録」に残した）
- [ ] `cargo test` が 0 で終わった（飛ばした・弱めた確認がない）
- [ ] 画面で観測できる受け入れ条件は実アプリで確認し、証拠（スクリーンショット）を
      残した。API の状態ダンプでも同じ状態が観測できる
- [ ] push の前に独立した `code-reviewer` が `APPROVE` を返した。指摘は1つずつ
      確かめ、直すか根拠を付けて退け、試験レポートに残した
- [ ] この変更の commit で CI が緑（最後まで見た）
- [ ] 判断があれば ADR を同じ commit で足し、関係する文書とルールを直した
- [ ] 試験レポートを `docs/test-reports/` に、証拠を `docs/test-reports/evidence/` に
      置いて push し、CI が緑
- [ ] 全部にチェックを入れ、commit・CI の URL・試験レポートへのリンクを
      コメントに書いて閉じた
